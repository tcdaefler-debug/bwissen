BWIssen als App

Leg BWIssen auf deinen Home-Bildschirm. Dann startet es wie eine App, und dein Fortschritt bleibt gespeichert. Welches Gerät hast du?

Schritt 1

Tippe in Safari unten auf Teilen.

Beim neuen iOS zuerst auf •••.

Schritt 2

Wähle Zum Home-Bildschirm und tippe auf Hinzufügen.

Eventuell etwas nach unten scrollen.

Schritt 3

Öffne BWIssen ab jetzt über das neue Symbol.

Gib dort einmal deinen Code ein. So bleibt dein Fortschritt dauerhaft, Safari löscht ihn sonst nach 7 Tagen ohne Besuch.

Schritt 1

Tippe in Chrome oben rechts auf ⋮.

In Samsung Internet unten auf ☰.

Schritt 2

Wähle Zum Startbildschirm hinzufügen.

Manchmal heißt es „App installieren“.

Schritt 3

Fertig, BWIssen liegt jetzt bei deinen Apps.

Dein Fortschritt bleibt gespeichert. Den Code musst du nicht neu eingeben.
