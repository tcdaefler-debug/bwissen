# BWIssen

Lern-App fürs Studium: ein Fach pro Kachel, Lernpfad, Probeprüfungen, Fragenkatalog und Spiele.

- `index.html`: Startseite mit allen Fächern und Einstellungen
- `modul-buchfuehrung.html`: Fach „Soll & Haben“ (Buchführung)

Der Lernfortschritt wird im Browser des jeweiligen Geräts gespeichert.
