    Auf den Home-Bildschirm

    iPhone / iPad (Safari):

    1. Unten auf das Teilen-Symbol tippen (Quadrat mit Pfeil nach oben).
    2. „Zum Home-Bildschirm“ wählen.
    3. „Hinzufügen“ tippen.

    Android (Chrome): Menü ⋮ → „Zum Startbildschirm hinzufügen“.

    Dein Lernstand wird nur auf diesem Gerät gespeichert. Öffne die Karten immer über dasselbe Symbol, dann bleibt alles erhalten. Einmal geladen, klappt es auch offline.
